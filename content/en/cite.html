How to cite FOCUS

Are you using FOCUS in a study, a report or a thesis? Cite the app like this (APA 7):

{{cite_author}}. ({{cite_year}}). FOCUS (Version {{cite_version}}) [Mobile app]. {{cite_link}}

State which version you used

In your methods section, state which version of the app and which platform you used, for example “FOCUS {{cite_version}} for iOS”. The version is shown in the app under Settings → About the app. You can also copy the reference there.

The observation protocol

A scientific publication on the observation protocol itself is in preparation. Once it is available it should be cited together with the app, and this page will be updated with the reference. Until then, cite the app.
