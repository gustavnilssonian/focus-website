Kort sagt

  • Observationerna sparas i din telefon.
  • Vestigio har ingen tillgång till dem och driver ingen server som tar emot dem.
  • Data lämnar telefonen bara när du själv exporterar, gör en sambedömning eller ansluter till ett Google-kalkylark.
  • Lärarens namn lämnar aldrig appen.

Uppgifter som sparas i telefonen

De uppgifter du fyller i (observatörens namn, lärarens namn, kommun, skola, årskurs, klass, ämne, antal elever och anteckningar) och kodningen av observationen. Uppgifterna finns kvar tills du raderar observationen eller avinstallerar appen.

Export

När du exporterar skapas en CSV-fil som du själv skickar eller delar. Lärarens namn tas aldrig med. Med valet Dela anonymt lämnas även observatör, skola, klass och kommentarer tomma.

Sambedömning

Vid sambedömning skickas observationsdata mellan de deltagande telefonerna över Bluetooth. Inget skickas via internet.

Google Kalkylark

Om du väljer att ansluta appen till Google Kalkylark:

  • Du loggar in med ditt Google-konto och ger appen behörighet att läsa och skriva kalkylark (https://www.googleapis.com/auth/spreadsheets).
  • Appen använder behörigheten bara för det kalkylark du skapat i appen eller valt att ansluta till. Appen listar, läser eller ändrar inga andra filer.
  • Du väljer själv vilka observationer som skickas. För varje vald observation skickas en sammanfattning direkt från telefonen till kalkylarket: tid, mätserie-ID, kommun, observatörens namn, skola, ämne, årskurs, klass, antal elever, anteckningar, mätpunkt, kommunkod, skolenhetskod och resultat. Lärarens namn skickas aldrig.
  • Uppgifterna går direkt mellan telefonen och Google. De passerar inte Vestigio.
  • Kalkylarket ägs av den som skapat det, till exempel en kommun eller skola, som är personuppgiftsansvarig för innehållet. Google behandlar uppgifterna enligt Googles villkor.
  • Du kan när som helst koppla från kalkylarket och logga ut i appen, och återkalla appens behörighet på myaccount.google.com/permissions.

Användningen av uppgifter som tas emot från Googles API:er följer Google API Services User Data Policy, inklusive kraven på begränsad användning (Limited Use).

Den här webbplatsen

Webbplatsen använder inga kakor och ingen besöksstatistik. Den publiceras via GitHub Pages, som för tekniska loggar (bland annat IP-adresser) enligt GitHubs integritetspolicy.

Frågor

Frågor om den här policyn: focus@vestigio.se. Frågor om uppgifter i ett gemensamt kalkylark ställs till den som äger kalkylarket.
