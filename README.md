# focus.vestigio.se

Webbplatsen för appen FOCUS: startsida, information för kommuner, support och
integritetspolicy, på svenska och engelska.

- Innehållet ligger i `content/sv` och `content/en`; stil i `assets/css`.
- `python3 build.py` bygger sidorna till `docs/`, som GitHub Pages publicerar.
- Färger och typsnitt följer appens grafiska profil
  (FOCUS-flutter: `docs/GRAFISK_PROFIL.md`).
- Kodboken i `files/` kopieras från FOCUS-flutter (`docs/FOCUS_codebook.csv`).

Typsnittet Inter ligger under SIL Open Font License (`assets/fonts/OFL-Inter.txt`).
